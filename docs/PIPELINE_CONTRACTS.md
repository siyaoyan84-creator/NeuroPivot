# Main-chain handoffs

All paths below are under the selected independent WORKDIR. The paths YAML must select that same workspace for all eight output directories. The complete-chain handoff inspection is static; core tensor/checkpoint behavior has additionally passed real CPU PyTorch checks. This is not an actual trained end-to-end run.

The original Llama base checkpoint is read by the actual AffectGPT `from_config` route as `checkpoint['model']`, after optional ckpt/ckpt_2 and CLI ckpt_3 precedence. It is not confused with a NeuroPivot EEG checkpoint (`model_state`), a task checkpoint (`task_token`), or a residual checkpoint (`adapter`). Existing base/foundation filenames were inventoried but their state contents were not loaded.

`run_pipeline.py` has been designed to emit real source/bridge/export/task/residual/inference CLI calls. Parser-only tests cover one fold and all five folds with six roles each. --execute was not run. No statement in this table proves successful dataset training or full base-model forward.

The new provenance fields and guard failures are intentional metadata extensions; they do not change the model calculations, labels, hyperparameters, frozen subject lists or normalization operation order. Old artifacts without sufficient anchor identity must be regenerated or justified by authentic launch/summary evidence; they are never auto-labelled anchor02.
